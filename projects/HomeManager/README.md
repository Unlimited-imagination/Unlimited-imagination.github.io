# Project HomeManager

Overview
-------
HomeManager is a sandbox web app to track household expenses, chores, and schedule recurring bills or reminders to improve domestic economy management.

Getting started
---------------
- Frontend: Vue 3 + TailwindCSS
- Backend: Lightweight API (Node + SQLite or serverless functions)
- Data privacy: keep sensitive data local or encrypted if persisted.
